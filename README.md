# Password Strength Analyzer

## 📌 Project Overview
The Password Strength Analyzer is a cybersecurity project that evaluates password security and helps users create strong, secure passwords.

## ✨ Features
- Checks password length.
- Identifies uppercase and lowercase letters.
- Checks for numbers and special characters.
- Classifies passwords as Weak, Medium, or Strong.
- Provides suggestions to improve password security.

## 🛠️ Technologies Used
- Python

## ▶️ How to Run
1. Clone or download the repository.
2. Install Python on your system.
3. Run the Python program:
   `python password_strength_analyzer.py`
4. Enter a password to check its strength.
